# 분수 키친 — 게임 제작 계획안

·

## 개요

모둠원이 한 주방에서 뛰어다니며 주문받은 요리를 시간 안에 만들어 내는 오버쿡드식 협동 요리 게임이다. 재료 창고에서는 분수의 나눗셈 문제를 풀어야 재료를 꺼낼 수 있고, 그 답만큼의 양이 그대로 냄비에 들어간다. 그래서 계산이 틀리면 요리가 망가진다. 시작 화면에서 '1학기'와 '2학기' 중 하나를 골라 단원에 맞는 문제만 나오게 한다.

- **가칭:** 분수 키친
- **대상:** 6학년 최대 25명(모둠 2~5명, 모둠별로 주방 하나) + 교사(방 호스트)
- **모티브:** 오버쿡드. 위에서 내려다보는 주방, 몰려드는 주문서, 재료 손질 → 조리 → 접시 → 서빙, 타거나 늦으면 실패, 별 3개 평가.
- **형태:** 웹앱(GitHub Pages) + 실시간 동기화(Firebase), 학생 개인 기기(휴대폰·태블릿·크롬북)로 참여
- **단원 선택:** 1학기 「분수의 나눗셈」(자연수로 나누기) / 2학기 「분수의 나눗셈」(분수로 나누기)

### 학습 목표

1. (1학기) 자연수 ÷ 자연수의 몫을 분수로 나타내고, 분수·대분수를 자연수로 나눌 수 있다.
1. (2학기) 분수 ÷ 분수, 자연수 ÷ 분수를 계산하고, 분수의 곱셈으로 바꾸어 계산할 수 있다.
1. 나눗셈의 두 뜻(똑같이 나누기 / 몇 번 들어가는지)을 실제 양으로 경험하고, 상황에 맞는 식을 세울 수 있다.
1. 계산 결과를 그림(계량 막대)으로 확인하며 답의 크기가 알맞은지 어림할 수 있다.

## 분수 표기 규칙

게임의 모든 화면(주문서, 문제 창, 말풍선, 냄비 표시, 결과 화면, 교사 화면)에서 분수는 교과서처럼 세로형으로 쓴다. 빗금(/)으로 쓰는 분수는 어디에도 쓰지 않는다.

```latex
\frac{3}{4}\,\text{kg} \qquad \frac{9}{5}\,\text{kg} \qquad 2\frac{1}{3}\,\text{L} \qquad \frac{3}{4} \div \frac{3}{8} = 2
```

- **진분수·가분수:** 분자를 위에, 가로선, 분모를 아래에 쓴다.
- **대분수:** 자연수를 크게 쓰고 그 오른쪽에 세로형 분수를 붙인다.
- **식:** ÷, ×, = 기호 사이에 세로형 분수를 한 줄로 늘어놓는다. 기호와 자연수는 분수의 가로선 높이에 맞춘다.
- **단위:** kg, L는 분수 오른쪽에 쓴다.
- **입력 칸:** 답을 넣는 칸도 같은 모양이다. 자연수 칸은 왼쪽, 분자 칸은 가로선 위, 분모 칸은 가로선 아래.
- **구현:** 화면의 모든 분수는 `js/ui/fracview.js` 하나로만 그린다(HTML 화면과 Phaser 주방 화면 공용). 저장값은 분자·분모를 나눠 둔 { n, d } 형태로만 다룬다.

이 문서에서는 문서 편집기의 한계로 문장 속 분수를 '4분의 3'처럼 읽는 말로 적고, 식은 위처럼 세로형으로 보였다.

## 핵심 플레이

주문서가 계속 들어오고, 모둠원은 각자 캐릭터를 움직여 재료를 꺼내고 손질하고 조리해 서빙한다. 수학은 재료 창고에서 일어나며, 창고에서 푼 나눗셈의 답이 곧 꺼내는 재료의 양이 된다.

[그림: 주방 흐름 · 6단계와 실패 루프 2개]

양이 틀린 재료가 냄비에 들어가거나 너무 오래 끓여 타면 쓰레기통에 버리고 창고에서 다시 꺼내야 한다. 손님이 먹은 접시는 더러운 채 돌아오므로 누군가는 설거지를 맡아야 한다.

### 한 판의 흐름

1. 화면 위쪽에 주문서가 나타난다. 주문서에는 요리 이름, 재료와 필요한 양(예: 토마토 수프 = 토마토 4분의 3 kg + 물 1과 2분의 1 L), 남은 시간이 있다.
1. 학생이 재료 상자 앞에서 '꺼내기'를 누르면 자기 기기에만 문제 창이 뜬다. 문제를 풀고 계량 막대에 답만큼 담으면 그 양의 재료를 들고 나온다.
1. 손질이 필요한 재료는 손질대에서 '썰기' 버튼을 연타한다.
1. 재료를 냄비·팬·오븐에 넣으면 조리가 시작된다. 냄비는 들어간 양이 레시피와 맞는지 표시한다(맞음 초록, 틀림 빨강).
1. 다 익으면 접시에 담아 서빙 창구로 가져간다. 주문 시간 안에 내면 점수와 팁을 받는다.
1. 라운드(3~4분)가 끝나면 점수에 따라 별 1~3개를 받는다.

### 오버쿡드에서 가져올 재미

- 동시에 여러 주문이 밀려 역할 분담과 말로 하는 소통이 필요하다("내가 창고 볼게!", "냄비 탄다!").
- 조리 시간이 지나면 탄다 → 더 지나면 불이 나고 소화기로 꺼야 한다.
- 스테이지마다 주방 구조가 달라 동선이 바뀐다(가운데 벽, 움직이는 발판 등).

## 학기별 문제 설계

문제는 '주문서가 요구하는 재료의 양'을 정답으로 삼아 거꾸로 만든다. 그래서 문제를 맞히면 레시피에 딱 맞는 양이 나오고, 틀리면 틀린 양이 냄비에 들어간다. 1학기는 '똑같이 나눈 한 몫'을, 2학기는 '한 봉지에 일정한 양씩 나누어 담으면 몇 봉지인지(나누어떨어지지 않으면 몇 배인지)'와 '1만큼에 해당하는 양'을 구하게 한다.

### 1학기 — 나눠 담기(자연수로 나누기)

창고의 재료는 큰 덩어리로 들어 있고, 똑같이 나눈 한 몫을 가져간다.

**s1-a 자연수 ÷ 자연수(몫이 1보다 작음)** — 치즈 3 kg을 4조각으로 똑같이 자르면 한 조각은 몇 kg일까요?

```latex
3 \div 4 = \frac{3}{4}\,\text{kg}
```

**s1-b 자연수 ÷ 자연수(몫이 1보다 큼)** — 우유 7 L를 3통에 똑같이 나누면 한 통은 몇 L일까요?

```latex
7 \div 3 = \frac{7}{3} = 2\frac{1}{3}\,\text{L}
```

**s1-c 분수 ÷ 자연수(분자가 나누는 수의 배수)** — 버터 7분의 6 kg을 3덩이로 똑같이 나누면 한 덩이는?

```latex
\frac{6}{7} \div 3 = \frac{6 \div 3}{7} = \frac{2}{7}\,\text{kg}
```

**s1-d 분수 ÷ 자연수(배수가 아님)** — 소스 4분의 3 L를 2병에 똑같이 나누면 한 병은?

```latex
\frac{3}{4} \div 2 = \frac{3}{4} \times \frac{1}{2} = \frac{3}{8}\,\text{L}
```

**s1-e 가분수 ÷ 자연수** — 밀가루 5분의 9 kg을 3봉지에 똑같이 나누면 한 봉지는?

```latex
\frac{9}{5} \div 3 = \frac{9 \div 3}{5} = \frac{3}{5}\,\text{kg}
```

**s1-f 대분수 ÷ 자연수** — 쌀 2와 4분의 1 kg을 3솥에 똑같이 나누면 한 솥은?

```latex
2\frac{1}{4} \div 3 = \frac{9}{4} \div 3 = \frac{3}{4}\,\text{kg}
```

### 2학기 — 나누어 담기와 1만큼의 양(분수로 나누기)

창고의 재료는 일정한 양씩 봉지·병 등에 담겨 있다. 레시피의 양을 채우려면 몇 봉지가 필요한지(나누어떨어지지 않으면 몇 배인지), 또는 1 kg(1 L)에 해당하는 양이 얼마인지 구한다. 답 × 한 봉지의 양이 그대로 꺼내는 양이 된다. '○ kg 컵으로 퍼 담기' 같은 표현은 쓰지 않는다.

**s2-a 분모가 같은 진분수 ÷ 진분수(나누어떨어짐)** — 육수 7분의 6 L를 한 병에 7분의 2 L씩 나누어 담으면 몇 병이 될까요?

```latex
\frac{6}{7} \div \frac{2}{7} = 6 \div 2 = 3\ (\text{병})
```

**s2-b 분모가 같은 진분수 ÷ 진분수(안 나누어떨어짐)** — 설탕 9분의 5 kg은 9분의 2 kg의 몇 배일까요?

```latex
\frac{5}{9} \div \frac{2}{9} = 5 \div 2 = \frac{5}{2} = 2\frac{1}{2}\ (\text{배})
```

**s2-c 분모가 다른 진분수 ÷ 진분수** — 토마토 4분의 3 kg을 한 봉지에 8분의 3 kg씩 나누어 담으면 몇 봉지가 될까요?

```latex
\frac{3}{4} \div \frac{3}{8} = \frac{6}{8} \div \frac{3}{8} = 6 \div 3 = 2\ (\text{봉지})
```

**s2-d 자연수 ÷ 분수** — 물 6 L를 한 병에 4분의 3 L씩 나누어 담으면 몇 병이 될까요?

```latex
6 \div \frac{3}{4} = 6 \times \frac{4}{3} = 8\ (\text{병})
```

**s2-e 분수 ÷ 분수(곱셈으로 바꾸기)** — 반죽 5분의 4 kg에 밀가루 3분의 2 kg이 들어가요. 반죽 1 kg에는 밀가루가 몇 kg?

```latex
\frac{2}{3} \div \frac{4}{5} = \frac{2}{3} \times \frac{5}{4} = \frac{10}{12} = \frac{5}{6}\,\text{kg}
```

**s2-f 대분수 ÷ 분수** — 면 1과 2분의 1 kg을 한 묶음에 4분의 3 kg씩 나누면 몇 묶음이 될까요?

```latex
1\frac{1}{2} \div \frac{3}{4} = \frac{3}{2} \times \frac{4}{3} = 2\ (\text{묶음})
```

### 답 입력과 확인 방식

- **입력:** 모든 답은 세로형 입력 칸(왼쪽 자연수 칸, 가로선 위 분자 칸, 가로선 아래 분모 칸)에 숫자 키패드로 넣는다. 입력하는 동안 계량 막대 그림이 실시간으로 채워져 답의 크기를 어림할 수 있다.
- **크기가 같은 분수:** 기본은 크기가 같으면 정답(예: 8분의 6과 4분의 3). 교사 설정에서 '기약분수·대분수로만 정답'으로 바꿀 수 있다.
- **확인 시점(교사 설정):**연습 모드: 틀리면 그 자리에서 '양이 이상해요'가 뜨고 다시 푼다. 재료는 맞아야만 꺼낼 수 있다.
- 실전 모드: 틀려도 그 양으로 재료가 나온다. 냄비에 넣어야 틀린 것이 드러나 요리를 버리게 된다. 오버쿡드다운 혼란과 협동 점검("그거 몇 kg이야?")이 생긴다.

**문제 기록:** 학생별로 푼 문제, 답, 정답 여부를 교사 화면에 모아 오답 유형을 볼 수 있게 한다.

## 주방과 레시피

스테이지 5개로 주방 구조와 요리가 바뀌며, 뒤로 갈수록 동시에 밀려드는 주문과 재료 수가 늘어난다. 레시피의 재료 종류는 고정이고, 양은 주문마다 문제 생성기가 정한다.

### 주방 설비

| 설비 | 하는 일 |
| --- | --- |
| 재료 상자 | 나눗셈 문제를 풀고 그 양만큼 재료 꺼내기 |
| 도마 | 썰기 버튼 연타(5회)로 재료 손질 |
| 냄비 · 팬 · 오븐 | 재료를 넣으면 조리 시작. 들어간 양이 레시피와 맞는지 초록/빨강으로 표시. 다 익은 뒤 8초가 지나면 타고, 더 지나면 불이 남 |
| 접시 선반 | 깨끗한 접시를 집는 곳 |
| 서빙 창구 | 완성 요리를 내는 곳 |
| 설거지대 | 돌아온 빈 접시를 씻는 곳(버튼 연타) |
| 쓰레기통 | 틀린 양이나 탄 요리를 버리는 곳 |
| 소화기 | 불난 조리기구를 끄는 곳 |

### 스테이지

| 스테이지 | 요리(재료) | 주방 특징 | 동시 주문 | 제한 시간 |
| --- | --- | --- | --- | --- |
| 1. 분식집 | 떡볶이(떡, 고추장 소스), 어묵탕(어묵, 육수) | 넓은 일자 주방, 손질 없음 | 2 | 180초 |
| 2. 피자 가게 | 치즈 피자(반죽, 치즈, 토마토 소스) | 오븐 사용, 치즈는 손질 필요 | 3 | 210초 |
| 3. 국수 가게 | 잔치국수(면, 육수, 애호박) | 가운데 벽으로 주방이 둘로 나뉨, 재료를 창구로 건네야 함 | 3 | 210초 |
| 4. 수프 식당 | 토마토 수프(토마토, 물), 감자 수프(감자, 우유, 버터) | 조리 시간이 짧아 잘 탐, 불이 자주 남 | 4 | 240초 |
| 5. 축제 푸드트럭 | 앞의 요리 섞어서 무작위 | 두 트럭이 발판으로 연결되어 동선이 김 | 4 | 240초 |

### 주문서

- 요리 그림, 재료와 양(예: 치즈 4분의 3 kg), 남은 시간 막대.
- 남은 시간이 30% 아래면 주문서가 흔들리고, 시간이 지나면 사라지며 감점된다.
- 양 표기는 1학기·2학기 모두 분수(대분수 포함)로 쓰며, 문제 생성기가 고른 정답과 같다.

## 게임 모드와 모둠 운영

모둠마다 자기 주방을 하나씩 받아 동시에 영업한다. 모둠끼리 점수를 겨루는 '요리 대회'와, 모둠 하나가 별 목표에 도전하는 '단독 영업' 두 가지 모드를 둔다. 단원(1학기/2학기)은 교사가 방을 만들 때 고르고, 한 게임 안에서는 바뀌지 않는다.

### 요리 대회(모둠 대항)

- **인원:** 최대 25명, 모둠당 2~5명, 모둠 최대 12개.
- **진행:** 교사가 고른 스테이지들(기본 1~3)을 차례로 영업한다. 모든 모둠이 같은 스테이지, 같은 주문 순서를 받는다.
- **스테이지 사이:** 30초 중간 순위와 별 개수 발표, 모둠 작전 회의.
- **결과:** 누적 점수 순위, 스테이지별 별 개수, 특별상(정확한 셰프: 오답 0, 빛의 서빙: 최다 서빙, 소방관: 불 끈 횟수).

### 단독 영업(소인수학급용)

- 모둠 1개(2~5명)가 스테이지 1~5를 차례로 영업한다.
- 스테이지마다 별 3개 기준 점수가 있고, 별을 모아 다음 스테이지를 연다.
- 우리 반 최고 점수와 별 개수를 교사 기기에 저장해 다음 시간에 기록 갱신에 도전한다.

| 2명 | 스테이지 기본값 − 1 | 최소 2개 |
| 3명 | 기본값 |  |
| 4~5명 | 기본값 + 1 | 주문 시간은 같음 |

역할은 정해 주지 않고 모둠이 스스로 나누게 한다. 처음에는 역할 카드(창고 담당 · 요리사 · 서빙·설거지)를 참고용으로 보여 주고, 스테이지 사이에 바꿔 보도록 안내한다. 창고 담당이 한 명에게 몰리지 않도록, 학생마다 푼 문제 수를 교사 화면에 표시한다.

## 조작과 화면

학생 화면은 오버쿡드처럼 주방 전체가 한 화면에 보이는 고정 카메라 탑다운 2D다. 기기는 가로 화면을 기본으로 하고, 왼쪽 엄지로 이동, 오른쪽 엄지로 행동한다.

### 화면 목록

| 화면 ID | 누가 | 내용 |
| --- | --- | --- |
| `host-setup` | 교사 | 단원(1학기/2학기), 나올 문제 유형(진도에 맞게 체크), 모드, 스테이지, 확인 방식(연습/실전), 정답 기준(크기 같음/기약분수만) |
| `host-lobby` | 교사 | 방 코드, 입장 목록, 모둠 자동 편성(2~5명) |
| `host-board` | 교사(TV) | 모둠별 주방 카드: 점수, 별 진행, 처리 중 주문, 불 경고. 학생별 푼 문제 수와 정답률 |
| `host-result` | 교사(TV) | 스테이지 순위, 누적 점수, 특별상, 많이 틀린 문제 유형 TOP 3 |
| `join` / `wait` | 학생 | 방 코드·이름 입력, 내 모둠·캐릭터 색 |
| `kitchen` | 학생 | 주방 게임 화면 |
| `pantry` | 학생 | 재료 상자에서 여는 문제 창(주방 위에 겹침) |
| `stage-end` | 학생 | 별 개수, 모둠 점수, 내가 푼 문제 수 |

### 학생 조작(kitchen)

- **이동:** 왼쪽 아래 가상 조이스틱. 캐릭터는 바라보는 방향의 설비를 자동으로 강조 표시한다.
- **A 버튼(집기/놓기):** 재료·접시·냄비 집기, 설비 위에 놓기. 재료 상자 앞에서 누르면 문제 창이 열린다.
- **B 버튼(사용):** 도마에서 썰기, 설거지대에서 씻기, 소화기 들고 뿌리기. 연타하면 진행 막대가 찬다.
- **키보드(크롬북):** 방향키·WASD 이동, Space = A, E = B.
- 들고 있는 물건과 양(예: 치즈 4분의 3 kg)이 캐릭터 머리 위에 말풍선으로 보인다.

### 문제 창(pantry)

- 화면 아래쪽 3분의 2를 덮는 창. 위에는 재료 그림과 문제, 아래에는 세로형 분수 입력 칸(자연수 왼쪽, 분자 위, 분모 아래)과 숫자 키패드, 계량 그림.
- 1학기: 계량 막대가 분모만큼 나뉘고 입력한 만큼 칠해진다. 2학기: 한 봉지(병·묶음 등) 그림이 입력한 수만큼 반복되어 쌓인다.
- 문제를 푸는 동안 내 캐릭터는 그 자리에 멈춰 있고, 다른 모둠원은 계속 움직인다. 창을 닫으면 문제는 버려진다.
- '이 주문용' 표시로 어떤 주문서의 재료인지 알려 준다(가장 오래된 주문부터).

## 판정 · 점수 · 연출

판정의 기준은 '조리기구에 들어간 재료별 양의 합이 레시피와 정확히 같은가'이다. 같은 재료를 여러 번 넣으면 더해지므로, 8분의 3 kg을 두 번 넣어 4분의 3 kg을 맞추는 것도 정답이다. 수치는 모두 `config.js` 상수로 둔다.

### 판정

| 상황 | 판정 | 결과 |
| --- | --- | --- |
| 재료별 양의 합 = 레시피 양 | 초록 | 조리 진행, 완성 후 접시에 담을 수 있음 |
| 아직 덜 들어감 | 노랑 | 조리 대기, 같은 재료를 더 넣을 수 있음 |
| 레시피보다 많음 또는 다른 재료 섞임 | 빨강 | '맛이 이상해!' 말풍선, 접시에 담을 수 없음 → 쓰레기통 |
| 완성 후 8초 경과 | 탐 | 접시에 담을 수 없음 → 쓰레기통 |
| 완성 후 16초 경과 | 불 | 소화기로 꺼야 함, 주변 설비 3초간 사용 불가 |

### 점수

| 항목 | 점수 |
| --- | --- |
| 서빙 성공 | 재료 1종당 20점(2종 요리 40점, 3종 요리 60점) |
| 팁 | 남은 주문 시간 50% 이상 +20, 25% 이상 +10 |
| 창고 문제 정답 | 1문제당 +5 |
| 주문 시간 초과 | −10 |
| 불이 남 | −10 |

### 별 기준(시작값)

| 스테이지 | 별 1개 | 별 2개 | 별 3개 |
| --- | --- | --- | --- |
| 1. 분식집 | 120 | 240 | 360 |
| 2. 피자 가게 | 150 | 300 | 450 |
| 3. 국수 가게 | 150 | 300 | 450 |
| 4. 수프 식당 | 180 | 360 | 540 |
| 5. 축제 푸드트럭 | 200 | 400 | 600 |

모둠 인원 보정은 동시 주문 수로 하므로 별 기준은 같게 둔다. 첫 수업 기록을 보고 조정한다. 요리 대회 순위는 누적 점수, 동점이면 별 개수, 그다음 창고 정답 수 순이다.

### 연출

- **화면:** 밝고 통통한 카툰풍, 위에서 비스듬히 내려다본 주방. 모둠원 캐릭터는 색이 다른 요리사 모자로 구분한다.
- **소리:** 주문 종소리, 칼질 '탁탁', 지글지글 조리음, 완성 '띵', 서빙 '찰칵'과 동전 소리, 탈 때 연기 경고음, 불 경보. 남은 30초부터 배경 음악이 빨라진다.
- **양이 틀렸을 때:** 냄비 위에 빨간 '?'와 '맛이 이상해!' 말풍선, 보글보글이 회색 연기로 바뀐다.
- **불:** 불꽃과 연기 입자가 커지고 주방 조명이 붉게 깜빡인다. 끄면 하얀 김과 함께 '휴~'.
- **스테이지 끝:** 별이 하나씩 '팡' 하고 찍히고, 모둠 점수가 차르르 올라간다.
- 그림과 소리는 오버쿡드 것을 쓰지 않고 직접 만들거나 라이선스를 확인한 무료 소스를 쓴다.

## 기술 명세

빌드 도구 없는 HTML·CSS·JavaScript(ES 모듈)로 만들어 GitHub Pages에 올린다. 주방 화면은 2D 게임 엔진 Phaser 3(충돌·스프라이트·입력 처리), 실시간 동기화는 Firebase Realtime Database(익명 로그인)를 CDN으로 불러온다.

### 폴더 구조

### 분수 계산(fraction.js)

- 분수는 항상 `{n, d}` 기약분수로 저장한다(d > 0).
- 함수: `frac(n, d)`, `fromMixed(w, n, d)`, `toMixed(f)`(자연수·분자·분모로 나눔), `add`, `sub`, `mul`, `div`, `eq`, `cmp`, `isReduced`.
- 화면에 보일 글자로 바꾸는 함수는 두지 않는다. 표시는 `fracview.js`의 `fracHTML(f, unit)`(HTML 화면)과 `drawFrac(scene, x, y, f, unit)`(Phaser 주방 화면)으로만 하며, 둘 다 세로형으로 그린다.
- DB에도 { n, d } 그대로 저장한다. 빗금(/)을 넣은 문자열은 저장에도 화면에도 쓰지 않는다.

### 문제 생성기(problems.js)

`makeProblem(semester, type, target)`은 정답 양(target)을 먼저 정하고, 그 정답이 나오도록 식을 거꾸로 만든다.

| 학기 | 만드는 방법(예) |
| --- | --- |
| 1학기 | 정답 양을 4분의 3으로 정하고 나누는 수 k를 2~5에서 고른다 → 나누어지는 수 = 정답 × k → k = 2이면 '2분의 3 kg을 2봉지에…'(가분수) 또는 '1과 2분의 1 kg을…'(대분수) |
| 2학기 나누어 담기 | 레시피 양 4분의 3 kg, 정답 q(2, 2와 2분의 1, 3 등)를 고른다 → 한 봉지의 양 = 레시피 양 ÷ q → q가 자연수면 '한 봉지에 8분의 3 kg씩 담으면 몇 봉지?', 아니면 '○ kg은 △ kg의 몇 배?' |
| 2학기 1만큼의 양 | 정답 6분의 5 kg, 묶음 양 5분의 4 kg을 고른다 → 주어진 양 = 정답 × 5분의 4 = 3분의 2 → '반죽 5분의 4 kg에 밀가루 3분의 2 kg이면 1 kg에는?' |

- 분모는 1학기 2~10, 2학기 2~12, 양은 3 이하로 제한한다. 생성 후 `div`로 다시 계산해 정답과 같은지 검사한다.
- 유형별로 문장 틀을 3개 이상 두어 같은 말이 반복되지 않게 한다.
- 유형 이름은 '학기별 문제 설계' 표의 순서대로 `s1-a``s1-f`, `s2-a``s2-f`로 부른다.

### 동기화 방식

별도의 게임 서버 없이 아래 원칙으로 맞춘다.

- **내 캐릭터 위치:** 각자 자기 위치만 초당 8회(움직일 때만) 기록, 다른 친구는 부드럽게 보간해서 그린다.
- **설비와 손에 든 물건:** 집기·놓기는 Firebase 트랜잭션으로 처리해 두 명이 같은 물건을 동시에 집지 못하게 한다.
- **조리 시간:** 조리 시작 시각(서버 시각)만 저장하고, 익음·탐·불 상태는 각 기기가 시간으로 계산한다.
- **주문:** 방의 시드로 주문 순서와 양을 계산하므로 모든 모둠이 같은 주문을 받는다.

### 실시간 데이터 구조

```
fkitchen/rooms/{roomCode}
  meta: { hostUid, semester: 1|2, mode: 'contest'|'solo', stages[], check: 'practice'|'real', answerRule, types[], seed }
  state: { phase: 'lobby'|'playing'|'stageEnd'|'final', stageIndex, startAt }
  players/{uid}: { name, teamId, color, online }
  teams/{teamId}:
    pos/{uid}: { x, y, dir }   (dir: 0 아래, 1 오른쪽, 2 위, 3 왼쪽)
    game:                      (집기·놓기 트랜잭션은 이 노드 전체에 건다)
      hands/{uid}: { kind, ingredient, unit, amount: { n: 3, d: 4 } }
      stations/{stationId}: { item } | { pot: { c: { 치즈: { n: 3, d: 4 } }, s: 조리 시작 시각 } } | { noPot: true }
      orders: { next, active/{orderId}: { i, startAt }, dueAt }
      served(서빙 수), score
    log/{pushId}: { uid, type, answer, correct, at }
```

- 손과 설비는 한 번에 함께 바뀌어야 하므로 `game` 아래로 묶는다. 초당 8번 바뀌는 `pos`를 같은 노드에 두면 트랜잭션이 계속 충돌한다.
- Firebase는 빈 값을 저장하지 않으므로 비어 있는 설비는 저장하지 않고, 지도에서 다시 만든다(`js/game/teamState.js`).

- 이 게임은 `fkitchen/` 경로만 쓴다(같은 Firebase 프로젝트의 다른 게임 데이터와 분리).
- 보안 규칙: 익명 로그인 필수, 자기 모둠 경로만 쓰기 가능, 교사(hostUid)만 meta·state 쓰기. 게임 종료 시 방 삭제.
- 문제의 정답은 학생 기기에서 계산되므로 개발자 도구로 볼 수는 있다. 수업용이라 허용하고, 교사 화면 기록으로 확인한다.

## 수업 적용

단원을 배우는 중에는 그 차시까지 배운 유형만 체크해 연습 모드로 짧게 하고, 단원 정리 차시에 모든 유형과 실전 모드로 요리 대회를 연다.

### 진도와 문제 유형

| 학기 | 배운 내용 | 켜는 유형 |
| --- | --- | --- |
| 1학기 | 자연수 ÷ 자연수의 몫을 분수로 | s1-a, s1-b |
| 1학기 | 분수 ÷ 자연수 | s1-c, s1-d, s1-e |
| 1학기 | 대분수 ÷ 자연수, 단원 정리 | s1-f, 전체 |
| 2학기 | 분모가 같은 분수의 나눗셈 | s2-a, s2-b |
| 2학기 | 분모가 다른 분수의 나눗셈, 자연수 ÷ 분수 | s2-c, s2-d |
| 2학기 | 분수의 곱셈으로 나타내기, 대분수의 나눗셈, 단원 정리 | s2-e, s2-f, 전체 |

### 40분 차시 예시

| 시간 | 활동 |
| --- | --- |
| 5분 | 모둠 편성, 조작 연습(스테이지 1 연습 모드 1분) |
| 25분 | 요리 대회 스테이지 2~3개(스테이지당 3~4분 + 중간 순위) |
| 10분 | 결과 화면의 '많이 틀린 유형 TOP 3'으로 함께 풀어 보기, 계량 그림으로 답 크기 확인 |

### 평가 연계

- 교사 화면의 학생별 정답률과 오답 기록으로 유형별 이해도를 확인한다.
- 게임에 나온 상황 문제(예: 한 봉지에 8분의 3 kg씩 담으면 몇 봉지)를 학습지에 식과 그림으로 다시 나타내게 한다.

## 고려사항

| 걱정되는 점 | 대응 |
| --- | --- |
| 한 학생이 문제를 피하고 서빙만 함 | 학생별 푼 문제 수를 교사 화면에 표시, 스테이지마다 역할 바꾸기 안내 |
| 실전 모드에서 틀린 양 때문에 좌절 | 처음 2~3번은 연습 모드, 실전은 단원 정리 때 사용 |
| 움직임이 끊겨 보임 | 위치 초당 8회 + 보간, 접속 약한 기기는 내 캐릭터 우선 반응 |
| 휴대폰 세로 화면 | 가로로 돌리라는 안내 화면, 태블릿·크롬북 권장 |
| 25명 동시 접속 | 움직일 때만 위치 기록해 쓰기 양을 줄임, 무료 요금제 동시 연결 한도(100) 안 |
| 교실 소음 | 모둠 자리 떨어뜨리기, 효과음은 학생 기기 작게·교사 TV 크게 |
| 오버쿡드 그림·소리 저작권 | 분위기만 참고하고 그림·소리는 직접 만들거나 무료 라이선스 확인 |
