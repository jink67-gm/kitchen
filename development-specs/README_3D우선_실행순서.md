# 우당탕! 수학 레스토랑 2.0 + 3D 업그레이드: Claude Code 진행 가이드

> 이 패키지는 **기존 게임 코드가 들어 있는 프로젝트 폴더**에 추가하는 '설명서'입니다. ZIP 안에는 게임 코드가 없으며, **기존 프로젝트를 덮어쓰지 않습니다.**

## 먼저 할 일

1. Claude Code에서 현재 작업 중인 **게임 프로젝트 폴더**를 연다. 가능하면 Git 커밋/브랜치로 원본을 백업한다. 이미 업그레이드한 최신 코드가 있다면 그 코드를 기준으로 작업한다.
2. 이 ZIP의 `기존_단계별명세/`, `3D_추가명세/`, `reference/` 폴더와 README를 프로젝트 폴더 아래 `development-specs/`에 통째로 복사한다. **게임의 `game.js`, `cloud.js`, `index.html` 등 원본 코드는 덮어쓰지 않는다.**
3. 참고 이미지는 저작권 보호 대상 원본 디자인을 복제하라는 뜻이 아니라 **카메라 각도·시각적 밀도·위계·가독성 참고용**이다. 모델/텍스처는 직접 만들거나 사용 허가가 명확한 에셋만 사용한다.
4. Chrome DevTools 플러그인은 브라우저 스크린샷·콘솔 오류 확인용, frontend-design은 UI 디자인용, Context7은 라이브러리 API 참고용이다. 3D 게임 엔진은 **Three.js**이며, Blender MCP는 커스텀 에셋을 만들어야 할 때 사용하는 **선택 사항**이다. 스킬/플러그인을 설치하는 것만으로 Canvas가 3D로 바뀌지는 않는다.
5. 처음에는 `로컬 단독 체험`을 목표로 한다. Firebase와 25명 실시간 동기화는 게임 메커니즘과 3D 이동이 안정된 뒤 검증한다.

## 기술적 원칙

- 기존의 수학 문제/레시피/게임방/점수 데이터는 최대한 보존하고, `game state`와 `rendering`을 분리한다.
- 브라우저용 3D 렌더링: **Three.js + glTF/GLB**, 화면 상단의 주문·진행 게이지·메뉴 UI는 HTML/CSS로 겹쳐 표현.
- 참고 장면과 비슷한 고정형 쿼터뷰(orthographic 또는 적절한 원근 카메라), 색감·광원·그림자는 독자적으로 설계.
- 에셋이 없으면 기본 로우폴리 메시로 프로토타입 → 품질 확인 후 허가된 GLB 적용. Blender MCP는 필수가 아니다.
- 원래 2D 렌더러는 **일시적으로 fallback**으로 유지한다. 3D 이식 안정화 이후 제거를 결정한다.
- 애니메이션 상태(걷기, 집기, 칼질, 굽기, 서빙)는 게임 상태 이벤트와 연결하며, 단순 화면 전환으로 끝내지 않는다.
- 캐릭터 이동/애니메이션은 가능한 한 로컬에서 부드럽게 보간하되, 경쟁에 영향을 주는 조리대 점유/주문/점수/소유권은 서버 검증 및 원자적 갱신을 고려한다.
- 학교 PC에서 WebGL 지원 여부와 성능을 먼저 확인하고 3D가 안 되는 컴퓨터에서는 2D 대체 또는 명확한 오류 안내를 제공한다.
- 각 단계에서 `DEVLOG.md`와 `TEST_CHECKLIST.md`에 실행 방법, 실제 테스트 결과, 미검증 항목을 남긴다.

## 1A 단계 프롬프트 — 기존 그래픽 코드에 손대지 말고

```
이제 development-specs/3D_추가명세/1A_3D주방_시제품.md에 적힌 1A 단계만 작업해줘. reference/참고_주방_시점.png와 참고_주문카드.png를 반드시 보고, 그 시각적 품질을 목표로 하되 원작 맵/모델을 복제하지 마.

기존 game.js 등 실제 게임 코드는 이 단계에서 고치지 말고, 독립적인 Three.js 3D 주방 시제품을 먼저 제작해. 3D 셰프 1명, 조리대/도마/팬/접시, 음식 아이콘/모델, 그림자·조명이 포함돼야 해.

브라우저 실행 화면과 스크린샷, 콘솔 오류 및 프레임 성능 결과를 보여줘. 스크린샷이 좋지 않다면 스스로 리터치하고, 1B 단계로 넘어가지 말고 기다려.
```

## 개발 환경/플러그인 관련 메모

- `frontend-design`: UI/카드/메뉴/보조 패널에 적용. 3D 주방 엔진은 아님.
- `chrome-devtools-mcp`: 실제 브라우저 조작, 콘솔/네트워크/성능 분석과 스크린샷 확인.
- `context7`: Three.js 등 공식 API 문서 확인을 위한 선택 사항.
- Blender MCP: 모델을 직접 생성·편집할 때만 필요. Blender 버전에 맞는 공식 설치 안내를 확인; 외부 제공 MCP는 권한이 넓을 수 있으므로 별도 작업 환경에서 실행.
- 기존 프로젝트 `firebase-config.js`의 값은 보고서나 스크린샷에 포함하지 말 것. Firebase 관리자용 서비스 계정 비밀키를 프런트엔드에 넣지 말 것. 접속이 쉽더라도 DB 읽기/쓰기 권한을 전체 공개하지 말 것.
