# 1B 단계 — 기존 게임 로직과 3D 시제품 연결

## 목적
시각적으로 승인된 3D 주방을 기존 수학 레스토랑의 로직에 연결하는 최소 수직 슬라이스를 만든다. 이 단계에서는 기능 범위를 1인/1개 레시피로 한정한다.

## 범위
- Three.js 렌더러/씬과 게임 도메인 상태(플레이어, 재료, 작업대, 주문, 점수)를 명확히 분리.
- 적절한 좌표계 대응(기존 2D 충돌/타일 좌표 ↔ 3D 월드 좌표).
- 기존 WASD/방향키 이동, E/Space 상호작용을 유지.
- 1개 레시피에 대해 재료 집기 → 수학 문제 → 조리대 가공 → 접시 재료 표시 → 서빙까지 실제 로직 연동.
- 캐릭터 보행 애니메이션, 재료 들기 상태, 상호작용 하이라이트.
- 원래 2D 렌더러를 임시 fallback으로 보존, 새 3D 모드 전환 가능하게 유지.
- 현재 25명 학급방/Firebase 코드는 삭제하지 않고 기존 통신 인터페이스와 호환되게 구현.
- 기존 그래픽 HUD는 그대로 두고 CSS 주문 UI가 3D 화면을 가리지 않도록 조정.

## 하지 말 것
- 전체 레시피, 주문 대기열, 5인 멀티플레이, 러시타임까지 한꺼번에 완성.
- 기존 game.js를 모두 갈아엎어 수학, 사용자 입장, 팀 점수 집계를 잃어버리기.
- 테스트 없이 2D 렌더러 삭제.

## 통과 조건
- 3D 주방에서 이동, 충돌, E키 사용, 문제 해결, 서빙까지 모두 동작.
- 접시/조리대 위 재료 표현이 게임 상태를 정확히 따른다.
- 스크린샷 및 손으로 재현 가능한 테스트 기록.
- 기존 2D 모드의 주요 동작 유지.
- 완료 후 멈춤.
