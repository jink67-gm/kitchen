# 6단계 — 좌측 상단 주문 카드·주문 대기열·러시타임·경쟁

공통 원칙과 직전 상태를 읽고 **주문·압박·점수 흐름**만 집중 구현하라.

1. 화면 **왼쪽 위**에 주문 카드(완성 음식 이미지, 재료 아이콘, 손질/굽기 아이콘, 남은 대기 게이지)를 큼직하게 노출. 주문이 여러 개면 먼저 도착한 순서로 최대 3개까지 나란히 표시. 캐릭터 위치가 잘리지 않도록 주방 HUD 레이아웃 조정.
2. `orderId`, `recipeId`, `createdAt`, `expiresAt`, `state`를 가진 실제 주문 큐 구현. 일반 모드 기본 1개, 러시 시작 시 2개 이상, 러시 중 약 10초마다 추가(3개 상한). 단지 카드 이미지만 추가하는 것이 아닌 **여러 주문과 여러 접시를 각각 실제 완성/서빙**할 수 있어야 한다.
3. 주문 대기 게이지(초록→노랑→빨강), 지연 시 팁 보너스만 소폭 감소. 수학 답을 천천히 생각하는 학생이 과도한 벌점을 받지 않도록 넉넉한 기본 시간과 교사 난이도 옵션. 주문 만료 시 정리/상태 전이 일관성.
4. 러시타임은 마지막 40초(짧은 라운드는 마지막 20%)에 한 번 발동: 이동속도 ×1.35, 걷기 모션 빨라짐, 추가 주문 발생, 붉은 테두리·경고음·주방 조명, 주문 카드 흔들림. 다른 플레이어 화면에서도 같은 시점 발동. 제한시간 종료 후 속도/연출 복귀.
5. 서빙 기본 100, 14초 내 연속 성공 +20씩 콤보, 재료 폐기 -8, 최소 0. 팀 점수와 개인 기여/정답 기록 분리. 4인 2대2와 팀 간 대항전(20~25명)은 공정 비교 지표 사용.

**테스트**: 동시 활성 1→2→3 / 3개 초과 없음 / 각 주문·접시 별개 처리 / 러시 속도 135% / 주문 증가 10초 간격 / 한 번만 발동 / 정확한 점수·콤보 / 5인 팀도 정상. 멈춰라.
