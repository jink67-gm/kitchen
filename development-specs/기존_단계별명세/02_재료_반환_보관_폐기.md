# 2단계 — 재료 상태·원재료 반환·보관대·쓰레기통

`00_공통개발원칙.md`, `01_현황진단_기준선.md`, 기존 문서와 코드를 읽어라. **이 단계의 기능만 구현**하고 종료하라.

1. 재료를 고유 ID/종류/상태/원재료통 ID/현재 위치를 가진 객체로 관리하고, 이전 `p.held` 문자열 인터페이스는 어댑터로 점진 교체하라. 같은 아이템이 두 장소에 동시에 존재할 수 없게 하라.
2. 원재료를 집을 때 `sourceBinId`를 기록한다. 손질 전 원재료를 **그 통**에 가져가 E/Space를 누르면 애니메이션과 함께 무료 반환한다. 다른 통 반환 거부. 원재료를 들었을 때 반환과 신규 채취를 헷갈리지 않게 한다.
3. **손질 완료 재료만** 보관대(공유 5칸)에 넣을 수 있게 한다. 빈손으로 E를 누르면 아이템 목록이 열리고 **원하는 재료를 골라** 꺼낸다. FIFO 자동 꺼내기 금지. 가공 전 원재료는 원래 통에 반환하도록 유도한다.
4. 손질 완료 재료만 음식물 처리통에 버리고 -8점(최소 0점); 탄 재료는 버리기만 허용하도록 확장 준비. Q 즉시 삭제를 완전히 제거한다.
5. 실제 주방 맵에 통·보관대·쓰레기통을 알아보기 쉽게 배치하고, 현재 들고 있는 재료/상태를 표시하라. 로컬과 온라인이 같은 상태 전이를 사용하도록 모듈화하고 온라인 동시 조작은 잠금/트랜잭션으로 보호하라.

**테스트**: 토마토 집기→토마토통 반환 성공 / 다른 통 반환 실패 / 손질 완료 재료는 원래 통 반환 실패 / 냉장 보관 5개 제한·선택 회수 / 폐기 -8 / Q로 삭제 불가 / 중복 복제 불가. 본 단계에서 아직 손질 시스템 개선을 하지 않았다면 테스트용 상태 전환은 별도 픽스처로 검증하라. 실행 가능한 빌드 유지. 결과를 보고하고 멈춰라.
