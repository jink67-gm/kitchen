# 9단계 — 6학년 2학기 수학 품질·학습 균형·접근성

공통 원칙을 읽고 이번 단계는 **교육적 정확성과 학습 경험 검증**에 집중하라.

1. 1~6단원 문항은행, 선택지, 오답, 힌트, 해설을 검토하라. 답이 여러 개인 문제·문장 오류·수치 계산 오류를 자동 검증하고, 6학년에게 적합하도록 수정한다.
2. 손질/굽기/믹싱/설거지에서 매 동작마다 문제를 요구하지 말고 **공정한 간격**으로 실제 요리 과정에 연결한다. 한 학생이 운반만 하고 문제를 풀지 않도록 팀별 참여를 유도. 학생별 시도/정답/오답/힌트 사용/단원 정보를 기록한다.
3. 난이도 '편안함/기본/도전'과 교사 옵션: 도마 연타 횟수, 작업 시간, 주문 인내심, 타기 유예시간, 러시 이동속도/주문 간격, 수학 문제 난이도. 과도한 압박을 피하고 계산 중 문제 창을 안정적으로 사용할 수 있도록 한다.
4. 교사 결과 화면: 팀 요리 점수와 학생별 학습 성과 구분, 오답 재학습 추천, CSV/엑셀에서 한글과 열 구분이 깨지지 않도록 한다. 개인정보 최소 수집(별명 중심).

**완료 기준**: 6개 단원별 샘플/자동생성 수십 개 이상 정답 검증, 힌트 작동, 학생 4명이 모두 풀이 기회를 가질 수 있는지 모의 검증, 설정 변경 시 플레이 가능 유지. 멈춰라.
