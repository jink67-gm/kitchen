# 3단계 — 도마 연타 조작·조리대 점유·진행 게이지

공통 원칙과 직전 결과를 읽고 이번 단계만 구현하라.

1. 도마에 재료를 놓고 수학 문제에 답하면 손질 작업 시작. 정답으로 즉시 `prepared`로 바꾸지 않는다.
2. E/Space의 실제 별도 키 누름 횟수(예: 10회, 조정 가능)로 게이지를 채운다. `event.repeat`는 제외하고, 지나치게 빠른/중복 이벤트는 방지한다. 충분히 연타할 수 있도록 키 입력을 가로채는 문제를 해결한다. 접근성 설정에서는 연타 횟수를 낮출 수 있다.
3. 칼질 중 캐릭터 팔/칼 움직임, 도마/재료 흔들림, 조각 파티클, 칼질 효과음, 진행 바를 동기화한다. 작업이 끝나면 완성물이 **도마 위에 실제 남아** 있고 플레이어가 E로 집어야 한다.
4. 도마는 `idle→reserved→working→ready` 상태. 작업 중이나 완성물이 남아 있으면 다른 재료로 사용 불가. 작업 플레이어가 나가거나 문제 창을 닫았을 때 예약이 영구 잠기지 않도록 안전한 취소·타임아웃을 둔다.
5. 다른 플레이어도 작업 중인 재료·게이지·점유 상태를 볼 수 있어야 한다. 조리대 위에 재료 아이콘과 상태 라벨 표시.

**테스트**: 수학 정답만으로 자동 손질되지 않음 / 1회 키 누름만 1회 인정 / 10회 연타 완료 / 작업 중 중복 사용 실패 / 완료품 도마 위 잔류·직접 회수 / 재접속 후 점유 상태 일관. 기존 기본 플레이 유지 후 멈춰라.
