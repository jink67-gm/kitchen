# 5단계 — 눈에 보이는 접시/트레이·요리 조합·직접 서빙

공통 원칙과 2~4단계 결과를 읽어라. **기존의 `tray` 체크박스만 채우고 서빙하는 동작을 실제 접시 기반으로 바꾼다.**

1. 빈 접시를 준비하는 접시대와 플레이팅대를 구축. 접시마다 `plateId`, `contents`, 연결 주문(`orderId` 또는 레시피 매칭), 완료 여부, 위치/소유자를 관리한다.
2. 손질/조리 완료 재료를 E로 접시에 하나씩 놓으면 **접시 위에서 어떤 재료가 들어갔는지 눈에 보이게** 한다. 빵·고기·치즈는 층으로, 샐러드는 접시 위 서로 다른 색 조각으로 구별. 주문 카드와 비교해 부족한 재료는 계속 표시한다. 서로 다른 학생이 동시에 한 재료를 두 번 넣지 못하도록 한다.
3. 주문 요구 조합을 충족하면 완성 요리 스프라이트로 변하고 '완성' 효과가 난다. **플레이어가 완성 접시/트레이를 집어 들고 실제 서빙대까지 이동해서 E를 눌러야만** 점수 획득. 재료 준비 완료만으로 자동 서빙 금지. 잘못된/미완성/탄 요리는 거절.
4. 서빙 후 접시는 더러워져 세척 대기 위치로 돌아온다. 싱크대에서 모션+게이지로 설거지하면 깨끗한 접시 재사용. 초기 접시 수와 세척 시간은 설정 가능.
5. 접시를 들고 이동하는 캐릭터 모션, 접시가 작업대 위에 놓이는 모션, 서빙 벨과 점수 팝업을 넣는다. 공유 주방의 접시 중복 집기/서빙/완료 경쟁을 막는다.

**테스트**: 재료가 접시 위에 실제로 보임 / 완성·미완성 시각 차이 / 완성접시를 직접 들고 서빙 / 미완성 서빙 불가 / 서빙 후 더러운 접시·설거지 후 재사용 / 동시 입력 시 중복 서빙 불가. 멈춰라.
