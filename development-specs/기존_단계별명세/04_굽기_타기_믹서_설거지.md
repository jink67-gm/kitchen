# 4단계 — 비동기 굽기·타기·믹서·싱크대

공통 원칙 및 앞 단계 완료 사항을 읽고 이번 단계에 집중하라.

1. 고기(프라이팬)와 빵(오븐/화덕)을 예로, 해당 설비에 재료를 올려놓고 수학 미션을 통과하면 **자율 타이머**로 굽기 진행. 학생은 다른 곳으로 이동할 수 있다.
2. `idle→cooking→ready→warning→burnt`를 시간에 따라 파생한다. 예시 설정값: 고기 6초 조리 + 4초 회수 유예, 빵 5초 조리 + 3초 회수 유예. 시작/완료/연소 시각 기반으로 진행 상태를 계산하여 렌더 프레임과 관계없이 동작하게 한다. 값은 설정에서 관리한다.
3. 해당 설비 위에 음식 스프라이트, 조리 게이지, 익음/타기 경고, 연기·불꽃·지글 효과음 표시. 익었으면 직접 집어야 하며, 못 집으면 타서 검게 변하고 접시에 넣을 수 없고 쓰레기통으로만 폐기한다. 탄 재료를 처리해야 설비가 비워진다.
4. 설비가 조리 중/완료품 놓임/탄 재료 남음일 때 다른 재료 투입 금지. 원자적 점유/회수. 시간 계산과 상태 변화를 여러 학생이 중복 확정하지 않도록 설계.
5. 믹서에는 젓기 애니메이션+게이지를 넣고, 설거지 싱크대에는 더러운 접시를 세척하는 작업+게이지를 넣는다. 이번 단계의 설거지는 테스트용 더러운 접시로 검증 가능; 본격적인 접시 루프는 다음 단계에서 연결.

**테스트**: 팬에 고기 놓고 다른 일 가능 / 익음→경고→탐 순서 / 완료 음식 직접 회수 / 탄 음식 플레이팅 금지 / 설비 점유 / 빵에도 동일 / 세척 완료 후 깨끗한 접시 반환. 멈춰라.
